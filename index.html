Autora: Irene Pastor Altur

Curso: 2º ASIX

Módulo: Implantación de Aplicaciones Web

Descripción de la práctica

Instalación, configuración y securización de phpMyAdmin en Ubuntu Server, utilizando Nginx, PHP y MariaDB.

Configuración de usuarios, métodos de autenticación, protección mediante htpasswd y preparación de scripts Bash para automatizar el proceso.
